## Findings considered and rejected (do not re-audit)

- **Readline fd leak in `stream()`/`notesIn()`** — `createReadStream` auto-closes on EOF; the `break` path calls `rl.close()`; consumer early-break propagates via async-generator return; the suite streams hundreds of times without fd exhaustion. Misreads stream semantics.
- **Hook re-derives the whole journal per prompt** — `latest()` walks backward and validates only the tail.
- **Terminal control-sequence injection** — confirmed defended: every stored/external text path to terminal/stdout routes through `stripTerminalControls`. Positive confirmation, not a finding.
- **Reading-render duplication across plain/json/terminal** — the selection logic IS shared (`readingTexts`); per-surface output shapes are deliberately different (the `/refactor` pass already concluded this).
- **`CryptoRandomSource` untested / `paths` command unguarded** — a 3-line stdlib passthrough (a test would test `randomBytes`); `resolvePaths` joins string literals with no user-supplied path segment.
